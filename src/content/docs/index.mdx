## API Reference

Полная спецификация доступна в [API Reference](/api/). Там находятся все маршруты, параметры запросов, response DTO и коды результатов.

Исходная OpenAPI 3.1 спецификация также доступна по адресу [`/openapi.yaml`](/openapi.yaml).

:::note
Документация неофициальная. Поведение API может меняться со временем.
:::
