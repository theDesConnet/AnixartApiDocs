## AnixartJS

TypeScript / Node.js SDK для Anixart API от автора этой документации.

Покрывает авторизацию, релизы, профили, статьи, каналы, коллекции, комментарии, эпизоды, уведомления, поиск, историю, настройки, импорт и экспорт.

Также есть типы моделей, enum'ы, ошибки, настройка `User-Agent`, таймауты и `AbortSignal`.

**GitHub:** https://github.com/theDesConnet/AnixartJS

**Статус:** активно развивается.

```bash
npm install anixartjs
```

```ts
import { Anixart } from 'anixartjs'

const client = new Anixart({
  token: process.env.ANIXART_TOKEN,
})

const { release } = await client.endpoints.release.get(101, true)

console.log(release.title_ru)
```

Список маршрутов и схем: [API Reference](/api/).

## vraestoren/anixart.py

**GitHub:** https://github.com/vraestoren/anixart.py

**Статус:** обновляется редко.

Синхронный Python-клиент. В README перечислено около 35 публичных методов.

Готовые методы есть для:

- вход и регистрацию;
- смену логина, почты и пароля;
- профили;
- списки профиля;
- релизы, оценки и избранное;
- комментарии к релизам;
- друзей и блок-лист;
- поиск;
- Discover;
- коллекции;
- счётчик уведомлений.

Нет готовых методов для статей, каналов, эпизодов, импорта/экспорта и большей части настроек.

`login()` сохраняет токен внутри клиента.

```py
from anixart import Anixart

client = Anixart()
client.login(
    login="example@gmail.com",
    password="password",
)

release = client.get_release_info(release_id=1)
```

Ответы возвращаются как `dict`; строгих моделей нет.

## AnixartPy

**GitHub:** https://github.com/PartyCorn/anixartpy

**Статус:** последнее обновление: сентябрь 2025.

Библиотека сосредоточена на статьях и каналах.

Есть методы для:

- получение статей;
- создание, редактирование, удаление и оценивание статей;
- комментарии к статьям;
- свои каналы;
- участников каналов;
- предложенные публикации;
- загрузку медиа;
- сборку содержимого статьи через `ArticleBuilder`.

Авторизационных методов нет. Клиент создаётся с готовым токеном.

```bash
pip install anixartpy
```

```py
from anixartpy import AnixartAPI

api = AnixartAPI(token="...")
article = api.get_article(123)

for comment in article.get_comments(page=0):
    print(comment.profile.login, comment.message)
```

Релизы, профили и остальные разделы API не покрываются.

## SantaSpeen/anixart

**GitHub:** https://github.com/SantaSpeen/anixart

**Статус:** последнее обновление: апрель 2025.

```bash
pip install anixart
```

В текущей версии готовая карта методов почти пустая: через обычный вызов вида `api.auth.login(...)` описан только вход.

У `AnixartAPI` есть низкоуровневые `get()` и `post()`, через них можно вызывать остальные маршруты вручную:

```py
api.get("/some/endpoint")
api.post("/some/endpoint", value="...")
```

Клиент сам хранит токен, выставляет `User-Agent` и проверяет поле `code` в ответе.

Транспортный слой готов, но готовых методов немного.

## libanixart

**GitHub:** https://github.com/AnAgTeam/libanixart_public

**Статус:** последнее обновление: июнь 2025.

C++-библиотека с отдельными API-модулями для релизов, профилей, эпизодов, коллекций и поиска.

В публичной версии есть методы для:

- релизов, оценок и избранного;
- комментариев к релизам;
- видео релизов и жалоб на видео;
- истории просмотров и списков профиля;
- профилей, друзей и блок-листа;
- настроек профиля и социальных ссылок;
- эпизодов, источников и типов озвучки;
- коллекций и комментариев к ним;
- поиска;
- Discover: обсуждаемое, интересное, рекомендации и «сейчас смотрят».

Регистрация и авторизация в публичной версии отключены.
